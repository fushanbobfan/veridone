## Manual release checks

- Public demo returns HTTP 200, loads its self-hosted assets, displays the synthetic-data label, and has no serious or critical axe finding.
- A fresh clone must pass `pnpm install --frozen-lockfile`, `pnpm quality`, built launch, health check, and first-page browser smoke before the tag is created.
- Release artifacts are source archives generated by GitHub from the signed-off tag; VeriDone does not publish an installer or claim OS sandboxing.
